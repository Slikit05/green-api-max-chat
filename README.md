# MAX Chat — GREEN-API

Тестовое задание: интерфейс для отправки и получения текстовых сообщений в MAX через GREEN-API.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который отобразится в консоли, и введите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.

Для получения сообщений у инстанса должны быть включены входящие уведомления, а поле `webhookUrl` должно быть пустым.

## Стек
React, JavaScript, Vite, GREEN-API, CSS

## Сборка

```bash
npm run build
```
